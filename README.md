# 🌿 EcoTracker — JoyRide командасы

**FIRST® LEGO® League Challenge · BIOGLOW™ 2026–2027** маусымына арналған инновациялық жоба.

EcoTracker — оқушыларды экологиялық сауаттылыққа үйретіп, күнделікті эко-әдеттер арқылы табиғатты қорғауға тәрбиелейтін веб-платформа.

## ✨ Мүмкіндіктер
- 🌐 Үш тіл: қазақша / русский / English
- 🌱 5 күнделікті эко-әдет, серия (streak) және «Жарқыл» серігі
- 💡 Фактілер, 📚 кейстер, 🧪 тесттер — ұпай аптасына бір рет беріледі
- 📦 Архив, 🆕 NEW белгісі, 🔒 админ панелі
- 🏆 Рейтинг, деңгейлер (Eco Rookie → Eco Legend), айына 5 дос шақыру
- 📸 Профиль суретін жүктеу немесе камерамен түсіру
- 🤖 EcoBot көмекшісі

## 📁 Файлдар
| Файл | Мақсаты |
|---|---|
| `index.html` | Сайттың өзі (барлық код, стиль және суреттер ішінде) |
| `content.json` | Фактілер, кейстер, тесттер және архив (админ жариялайды) |
| `.nojekyll` | GitHub Pages файлдарды өзгертпей көрсетуі үшін |

## 🚀 GitHub Pages арқылы жариялау
1. GitHub-та жаңа репозиторий ашыңыз, мысалы `ecotracker`.
2. **Add file → Upload files** арқылы осы папкадағы барлық файлды жүктеңіз.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. 1–2 минуттан кейін сайт ашылады: `https://<логин>.github.io/ecotracker/`

## 🔄 Контентті апта сайын жаңарту
1. Сайттың төменгі жағындағы **🔒 Админ** сілтемесі арқылы кіріңіз (немесе мекенжайға `#admin` қосыңыз).
2. Фактілерді, кейстер мен тесттерді өзгертіп, **🚀 Жариялау** батырмасын басыңыз — `content.json` жүктеледі.
3. Репозиторийде `content.json` файлын жаңасымен ауыстырыңыз (**Add file → Upload files**, сол атаумен).

## ⚠️ Маңызды
- Бастапқы админ құпия сөзін **міндетті түрде** өзгертіңіз (Админ → 🔑 Пароль), содан кейін `content.json`-ды қайта жүктеңіз.
- Сайттың сервері жоқ: тіркелу, ұпай және әдеттер әр қолданушының өз браузерінде сақталады.
